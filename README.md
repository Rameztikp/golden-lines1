# الخطوط الذهبية — الموقع ولوحة التحكم

موقع عربي RTL لدار أزياء زفاف، مع لوحة إدارة متصلة بقاعدة بيانات ورفع صور دائم. يحتفظ بالهوية الذهبية، الصور الحالية، وعارض الفستان متعدد الزوايا.

## الدخول والإدارة

- الموقع: https://golden-lines-bridal-jeddah.moadeebprog.chatgpt.site/
- لوحة التحكم: `/admin` (رابط «إدارة الموقع» في أسفل الصفحات).
- الدخول باستخدام حساب ChatGPT المصرح له. حساب مالك الموقع الحالي هو المالك الأول للوحة.
- الموقع ما زال خاصًا؛ لم تتغير سياسة المشاركة. إضافة بريد إلى فريق اللوحة لا تمنحه تلقائيًا حق زيارة الموقع الخاص؛ يلزم منحه حق الزيارة من مشاركة الموقع أيضًا.
- البريد الذي يحدد المالك محفوظ في إعداد تشغيل `ADMIN_OWNER_EMAIL` على Sites، وليس في الملفات العامة. لا توجد كلمة مرور افتراضية.
- تُربط هوية العضو المستقرة ببريده المصرح به عند أول دخول. لا يمكن حذف المالك أو تخفيض صلاحياته من اللوحة.

## ما تديره اللوحة

1. **الفساتين:** إضافة وتعديل ونسخ وحذف، رمز التصميم والوصف، المصمم والمجموعة، الأكمام والقصة، الألوان والمقاسات، ترتيب العرض، المسودة/النشر، الصورة الرئيسية والتفاصيل والخامات والعناية.
2. **زوايا الفستان:** إضافة صور بزوايا 0–359، رفع مجموعة صور بالترتيب، حتى 72 زاوية، حذف واستبدال الصور. العارض يدعم السحب والدوران التلقائي والتكبير حتى 4× والتحريك وملء الشاشة. ليان يحتفظ بزواياه الـ12 الأصلية.
3. **المجموعات والمصممون:** إضافة وتعديل وحذف. يمنع حذف عنصر ما زال مرتبطًا بفساتين.
4. **مكتبة الصور:** رفع JPG وPNG وWebP حتى 10 ميجابايت للصورة، اختيار الصور ونسخ روابطها وحذف غير المستخدمة. تحفظ الصور الجديدة في R2 وبياناتها في D1. الصور الأصلية تبقى ضمن ملفات الموقع.
5. **الحجوزات:** استقبال الطلبات من الموقع، إضافة طلب يدوي، البحث والتصفية بالتاريخ والحالة، تغيير الموعد، تأكيد/إكمال/إلغاء، وملاحظات داخلية. تمنع قاعدة البيانات تجاوز سعة الموعد عند التأكيد. زر واتساب يفتح رسالة للمراجعة والإرسال اليدوي.
6. **الرسائل والمشتركون:** حفظ نماذج التواصل والاشتراك، مراجعة الحالة والأرشفة وتصدير CSV. لا توجد خدمة إرسال حملات بريدية آلية.
7. **محتوى الصفحات:** اختيار النصوص والصور داخل المعاينة وتعديلها، مع إظهار أو إخفاء أقسام الصفحات التعريفية. بيانات بطاقات المنتجات والمصممين والمجموعات تُحرر من أقسامها المخصصة. لا يدعم المحرر حقن HTML أو JavaScript مخصص.
8. **الإعدادات:** الاسم والشعار والألوان، واتساب والبريد والعنوان والخريطة وساعات العمل والروابط الاجتماعية، الشريط العلوي، إحصائيات المعرض، دليل المقاسات، عنوان البحث والوصف.
9. **توافر المواعيد:** إيقاف أو تفعيل استقبال الطلبات، ساعات الزيارة، الأيام الأسبوعية المغلقة، تواريخ الإجازات، الخدمات وسعة كل ساعة.
10. **الفريق:** مالك (كل الصلاحيات)، محرر (المحتوى والصور والإعدادات)، استقبال (الحجوزات والرسائل والمشتركون). التحقق من الصلاحيات على الخادم لكل طلب.
11. **النسخ الاحتياطي وسجل النشاط:** تنزيل واستعادة محتوى الموقع بصيغة JSON، تصدير سجلات العملاء بصيغة CSV، وعرض آخر 200 عملية. ملف محتوى JSON يتضمن روابط الصور، ولا يتضمن بيانات ملفات الصور نفسها؛ مكتبة R2 تبقى مستقلة. استعادة المحتوى لا تستبدل بيانات العملاء أو الفريق.

الحفظ ينشر تعديل المحتوى فورًا دون إعادة بناء الموقع. مراجعة الإصدار تمنع الكتابة فوق تعديل أحدث أجراه عضو آخر. تبقى مدخلات النماذج عند فشل الحفظ ليتمكن المستخدم من مراجعتها.

## بيانات عليك اعتمادها

رقم واتساب والبريد والروابط الاجتماعية تُركت فارغة لتعبئتها من «إعدادات الموقع» كما طلبتِ. لا تظهر روابط اتصال تجريبية للزوار عند تركها فارغة. العنوان العام جدة حتى تحديثه.

أسماء المصممين والبيانات والصور الحالية تمثل محتوى المشروع التجريبي. الإحصائيات ودليل المقاسات قابلان للتعديل ويجب اعتماد القيم التجارية الصحيحة قبل فتح الموقع للجمهور. آراء العرائس الحالية معنونة كنماذج توضيحية ويمكن تحريرها أو إخفاء قسمها.

**الحجوزات والرسائل محفوظة فعلًا**، لكن لا يُرسل بريد أو واتساب تلقائيًا. تأكيد الحجز في اللوحة لا يرسل إشعارًا إلى العميلة؛ يتواصل الفريق معها.

العارض **فوتوغرافي متعدد الزوايا**، وليس نموذج GLB هندسيًا أو محاكاة قماش. إضافة صور إلى الزوايا لا تولّد نموذجًا ثلاثي الأبعاد. التجربة الافتراضية على جسم العميلة ليست مفعلة؛ يُعرض بديل الحجز داخل المعرض بوضوح.

## البنية

- `public/`: الصفحات وCSS وJavaScript والصور الأصلية ومكتبة Three.js.
- `public/admin.html`, `admin.js`, `admin.css`: لوحة التحكم.
- `public/main.js`, `site-cms.js`: الكتالوج والمحتوى المحفوظ والنماذج.
- `public/dress-viewer.js`: عارض الزوايا الذي يستخدم إعدادات كل فستان.
- `server/worker.mjs`: واجهات API، الصلاحيات، خدمة الصور وتوجيه الصفحات.
- `server/seed.json`: المحتوى الافتراضي فقط؛ لا يعاد زرعه فوق المحتوى الذي حفظته الإدارة.
- `db/schema.ts`: مخطط Drizzle، و`drizzle/`: الترحيل الأول وبياناته الوصفية.
- `scripts/build.mjs`: إخراج Worker في `dist/server/index.js` والأصول في `dist/client` والبيانات الوصفية والترحيلات في `dist/.openai`.
- `scripts/dev.mjs`: خادم محلي باستخدام SQLite وملفات صور في `.local/`، للاستعمال المحلي فقط.
- `tests/server.test.mjs`: اختبارات الصلاحيات والحفظ والتعارض والحجوزات والملفات.
- `.openai/hosting.json`: هوية الموقع وربطا `DB` و`BUCKET`، دون أسرار.

## التشغيل المحلي

يلزم Node.js 24 أو أحدث (لدعم SQLite المدمج):

```sh
npm ci
npm run dev
```

افتحي `http://127.0.0.1:4174/admin`. المعاينة المحلية تستعمل دخولًا وهميًا محصورًا بخادم loopback وحساب `owner@local.test`، ولا يُنشر هذا الخادم أو أسلوب الدخول على الإنترنت. يستبعد البناء `.local` وكل بيانات الاختبار. الموقع الآن يحتاج الخادم؛ تشغيل `python -m http.server` وحده لم يعد كافيًا.

```sh
npm run build
npm test
```

بعد تعديل المخطط فقط: `npm run db:generate` ثم مراجعة SQL. لا تعيدي كتابة ترحيل منشور؛ أضيفي ترحيلًا جديدًا. تطبيق ترحيلات الإنتاج تديره Sites عند النشر. المعاينة المحلية تطبق الملفات التي لم تطبق سابقًا فقط.

## ضوابط البيانات

نتائج المراجعة والاختبارات والإصلاحات وحدودها موثقة في [تقرير الفحص](QA-REPORT.md). يشمل `npm test` إعادة البناء واختبارات قاعدة البيانات والتصدير. حدّثي البناء بعد إضافة صور ثابتة لتحديث قائمة الصور المعتمدة.

فحوص خادم للمدخلات، طلبات SQL محضرة، حماية Origin للإجراءات المعدلة، حدود للحجم والمعدل، فحص توقيع ملفات الصور، منع حذف صورة مستخدمة، ومفاتيح منع التكرار للنماذج. المخولون فقط يمكنهم قراءة بيانات العملاء. لا تُستخدم ذاكرة المتصفح مصدرًا لبيانات الإدارة؛ المفضلة وحدها محلية للجهاز.

الأصول تخدم عبر Worker مع [ربط الأصول الرسمي في Cloudflare](https://developers.cloudflare.com/workers/static-assets/binding/). إعداد `run_worker_first` في البناء يمرر الطلبات عبر التوجيه والتحقق قبل خدمة الصفحات.
